500 — Server Error

The application encountered an unexpected error.

Most common fix:

Set these environment variables in your Vercel Dashboard → Settings → Environment Variables:

  • SECRET_KEY — any long random string
  • DATABASE_URL — your Neon PostgreSQL connection string
  • CSRF_TRUSTED_ORIGINS — your Vercel domain (e.g. https://your-app.vercel.app)
Verify your setup:

Visit /health/ to check database connectivity.

If database shows an error, run migrations on your Neon database:

DATABASE_URL="your-neon-url" python manage.py migrate
